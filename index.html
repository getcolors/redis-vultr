DEPLOYMENT · VULTR · REDIS

redis-vultr

Desired state for one Redis 7.2 server on one Vultr instance in Amsterdam, converged by the redis Package Skill: loopback only, an SSH tunnel as the client path, an append-only file for persistence, and RDB backup sets in Cloudflare R2 with a rehearsed restore.

Desired state only. This repository is a colors.yml, an installed launcher, an .envrc and a devenv.nix. Everything else is generated under .colors/ or secret in .envrc.private.

Use

./green build
./green create --dry-run
./green create
./green describe
./green rehearse

Connecting

ssh -L 6379:127.0.0.1:6379 redis-vultr
REDISCLI_AUTH=$(ssh redis-vultr cat /etc/redis/secrets/password) redis-cli -p 6379

Recovery

A restart recovers from the append-only file, proven on every converge. RDB sets land every six hours under redis-vultr/redis/ in the backup bucket with completion markers; ./green rehearse restores the newest into a scratch instance of the pinned image, reads the smoke key back, and writes .colors-recovery-verified.
